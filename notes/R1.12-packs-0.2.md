## 2. The ten new DSP sections [verified: `tools/dspsplice/build.py` `pack_recipe`, `PACKS`]

Every hook stub in L1 block 1; the flanger and its glue after them, flg_sync.c in code2 (DC02's arrangement); the
compressor in code3, its glue and tail reader in code4 (DC02's); the spring and its glue in code2 after flg_sync.c,
its constants and SpgSlot in the stock reverb's DDR region (SP02's); the tape echo fitted per function into the room
left (TE01's key `fit`, alignment-aware). The diet: each effect's never-called functions dropped; share mode
"first": every fxmath.h helper that two files have, in one copy, the first file's in link order (as
scripts/patcher_budget.py measured all fifteen). DC02's pass (ABs). Every code section inside a proven range (the
build's check); every function reached from the hooks; an absent effect's hooks stay stock (their bytes checked).
Rebuilding DC02, SP02, SC01 and TE01 with the extended build.py gives their images byte for byte.

## 6. The patcher [verified: `tools/patcher/`]

- **Packs:** `make PACKS="CFEE CFTE CFES EFTS CETE CEES EFTE EFES EETS CEEE EFEE EETE EEES EEEE"` (the release order:
  CFEE first, which the app opens on). Each pack pinned to its build's sha256 and its ACCEPT report; stockcheck: no
  16-byte run of Elektron's in any. CFEE and CFTE carry "tested on a Digitone II, 29 Oct 2026" (BA05 and TE01 on the
  unit), the other twelve "not yet tested on a unit".
- **The app** 0.2.0 (build 2), universal, the fourteen in that order (`app/build.sh`). `app/test.sh` (its Core with
  the six-pack, one-pack and release sets; for the release set every pack from Elektron's .zip, the folder and the
  file, byte for byte, every other build refused; the catalog covers the packs, one per combination; Tests/main.swift
  now reads a 0.2.0 pack's effects from its name): all passed. `make test`: 45 passed (the `--list` check no longer
  expects a pack not yet tested: all six old packs have been played).
- **The Terminal tool** with the fourteen: every pack byte for byte from a copy of the stock file (arm64), CFTE and
  EEEE also on x86_64 (Rosetta), CETE from Elektron's .zip; `--list` names the base features (cli.c had only DJVU's
  name) and leaves Overbridge out, as the app does.
- **Sizes:** the app 18 MB (zip 15.5 MB; 0.1.0's 1.5 MB), the Terminal tool 32 MB (zip 30 MB): the packs hardly
  compress, and a universal tool carries them in both slices. Sharing the base between packs would shrink both.
- **Screens** (`app/screens.sh`): `docs/images/patcher-0.2.0-start.png` (CFEE when it opens) and
  `patcher-0.2.0-done.png` (CFTE made); the README's install picture is the second.
- **Release:** `out/release/0.2.0/`: both signed with the Developer ID (hardened runtime, timestamp), zipped.
  Notarization waits for the owner: the keychain profile redeemer-notary wasn't found from this session.
