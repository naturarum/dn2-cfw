# T3.5: recording the stock effects (the "A" side of the A/B)

Date: 2026-10-06. For the owner, at the unit. Written with T3.11 (the Mac workbench); parameter names and
ranges from T3.3. About an hour. Nothing is flashed or changed on the unit.

## Idea
Play the workbench's dry files from the Mac into the Digitone II's inputs, send them through one stock
effect at a time, and record the unit's main output. The A/B page then compares the stock effect and
the new one on the same material.

## 1. Wiring (MOTU M2)
- M2 **LINE OUT L/R** -> DN2 **IN L/R**. DN2 **MAIN OUT L/R** -> M2 **IN 1/2** (line).
- **M2 direct monitoring off** (the MON buttons). Otherwise the unit's output comes back into its input
  and feeds back.
- Mac audio at **48 kHz**. Any DAW that plays and records at once (Logic, Reaper, Audacity) works: one
  stereo track playing the dry file to outputs 1/2, one stereo track recording inputs 1/2, 24-bit.
- Levels: M2 output knob about 3/4. On the unit, MIXER 5 (External: FUNC+MOD, DOWN x4) **IN** at 127,
  **DUAL** off. Set the M2 input gain so the loudest take peaks around -6 dBFS, then **leave every gain
  alone for the whole session** (write down where the knobs are).

## 2. Unit setup
- A new, empty project at **120.0 BPM**, sequencer stopped, so only the input sounds.
- MIXER 5: the input's sends **CHR (G), DEL (E), REV (F)** at 0, except the one for the effect being
  recorded, which goes to **127**.
- Delay and reverb pages: **REV** send (H on the delay page) and chorus **DEL/REV** at 0, so one effect
  plays at a time. The **VOL** (LEVEL) of the effect being recorded at 127.
- Compressor: SETUP (FUNC+FLTR) > KIT > COMPRESSOR ROUTING, page 2: IN L and IN R **on**, SEND FX off,
  all tracks off. For the delay, chorus and reverb takes set the compressor to MIX 0 (dry), so it does
  not touch them.
- Write down what the **screen** shows for each knob, not what you think it is: TIME shows `v+1`,
  bipolar knobs show `v-64`, RAT shows the ratio. If a value below can't be set exactly, note the
  nearest one.

## 4. Files
- Export each take as **48 kHz, 24-bit, stereo WAV** with the names above, untrimmed (the alignment is
  done later against the `path_` takes).
- Put them in `out/T3.11/stock/` and add a `takes.txt` there with one line per take: the name, every knob
  value as the screen showed it, and anything odd. Then `make renders` in `fx/` adds them to the A/B page.
- A copy of this plan's table, ticked off as you go, is the easiest `takes.txt`.

## Open
- Whether the input sends (MIXER 5 CHR/DEL/REV) are pre or post the IN level. If they are pre, IN at 0
  with DEL at 127 gives a wet-only take, which is the cleanest comparison: worth one extra take
  (`delay_01b_pluck_wet.wav`) if it works.
- If the unit offers USB audio or Overbridge, recording digitally (no converters, no clock drift) would be
  better than the M2 loop. Not checked. [guess]
