## 1. The owner's request

"Could we put the compressor control glyphs on our new multiband compressor again? ... ratio is now a knob, but it
only goes to 20, so effectively in the UI it feels like I can only turn it a quarter of the way and then it stops."
Since CMP1 every band knob but MIX borrowed the display entry of Makeup Gain (row `0x99`): the default dial, the
owner's placeholder (T6.4 2.2). A dial over 0..8 stops a quarter of the way round.

## 2. What changed [verified: the build's checks, the emulator]

The glyph is the display entry's `+0x14` std::function (T5.0 2.5); param-grow copies a new row's entry from the stock
row it names (`look`, T6.5 1.5). **param-rows 0.4** changes only `look`:

| knob (LOW `0x141..`, MID `0x147..`, HIGH `0x14d..`) | look | glyph | frames: value -> frame |
|---|---|---|---|
| THR | `0x96` (was `0x99`) | the stock THR curve (threshold line moving up) | 15, 0..127 spread |
| ATK, REL | `0x97`, `0x98` | the stock slider | 13, 0..127 spread |
| MUP | `0x99` (as before) | the stock MUP dial (it was already the stock one) | 96 |
| RAT | `0x9a` + comp-ui's function | the stock ratio steps, labelled 1.5 .. 20 | 9: see below |
| MIX (`0x152..0x154`) | `0x9e` (since 0.3) | DRY/CMP | 18 |
| XOVR (`0x146`, `0x14c`) | `0x99` (kept) | the default dial | 96 |

The crossovers keep the dial: the only frequency-style stock glyphs are filter curves (the sidechain filter's
low-pass/high-pass steps, the chorus HPF curve), which would read as "this band is filtered", not as a split point.

**RAT.** The stock function draws frame `value >> 8` of an 8-frame strip whose frames carry the ratio's number
(1.5, 2, 3, 4, 6, 8, 16, 20). Our range is 0..8: 1.00 (the band off), then the 8 stock ratios. Borrowed as it is, every
ratio would show the next one's number and 16.00/20.00 the same frame. **comp-ui 0.3** puts its own function
(`compui_rat_draw`) into the three ratio rows' entries (only where the stock Ratio function is, before a band page
draws): values 1..8 draw the stock frame for the same ratio (frame value - 1; 20.00 = the last frame), and **1.00 draws a
ninth frame in the stock style: the 1.5 frame's straight line without the dotted threshold, labelled "1.0"** (19 x 17,
the stock mask; ASCII art in `compui.c`). So the glyph travels over the whole range, the last value shows the last
frame and every step changes the picture.

Borrowing the stock entries also brings the stock rows' other display fields: RAT's flags 5 (the label RAT stays under
the knob while it turns, as on the stock page; the value is in the header, "Low Ratio=4.00"), its encoder feel, and
the stock FUNC + turn function of each row (THR, ATK, REL, RAT, MIX: to the end of the range; MUP: to the default).
Until FL01 FUNC + turn sent every band knob to its default. Names, ranges, value texts, k and storage are 0.3's: no kit
changes. Not p-lockable as before (flags | 8).
