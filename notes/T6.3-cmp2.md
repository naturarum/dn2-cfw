## Summary

CMP2 = CMP1 + **comp-link-dn2 0.1** (ColdFire: one site, the frame handler's driver call) + the DSP "CMP2" (a frame-tail
reader in the compressor glue). Each band page's THR, RAT, ATK, REL, MUP and the two crossovers now set their band on
the DSP. MIX, SCS and VOL stay the stock rows. The band values are not saved (CMP3).

| site | stock | CMP2 |

if clear, straight to `jmp 0x400cf922`; else word 0 = `0xC3B1` at `0x80003a12`, word 1 = `compl_seq + 1` (`0x47e012f0`,

free (a C call) [verified: source, link map, build check]. Below the appended blob every byte that differs from GT01 is
in core 0.2's site, a comp-ui site, comp-link's site, or a GT01 site whose operand moved with the link layout to the

Link: `.run` `0x47e00000-0x47e012dc` (4,828 bytes; comp-link's `.run` is linked after core's, so comp-ui's and
param-rows' symbols moved by 0x5c, `core_pagerecs` to `0x47e01290`), `.bss` `0x47e012dc-0x47e012f8`, blob 4,892 bytes;

### 2.2 The tail (T6.4 3.4, as built)

| tail word | frame byte | content |
|---|---|---|
| 0 | `0xa80` | `0xC3B1` (the low byte is the layout, 1) |
| 1 | `0xa82` | sequence, +1 per tail written |
| 2..28 | `0xa84..0xab8` | the smoothed row-16 words k 70..96 (k = 68 + word); k 70..86 the band rows (T6.4 2.2), k 87..96 spare |
| 29 | `0xaba` | `~(sum of words 0..28)` & 0xffff |

The handler sends the frame before it runs the smoother (`FUN_400db28e` at `0x4002717e`), so a tail carries the
values smoothed in the previous pass: one frame (0.67 ms) of latency [verified in the emulator: the first pass from a
snapshot carries the snapshot's smoothed words]. The smoother settles exactly on `v << 8` on the unit
[inferred from the EMAC code (T3.3); verified in a model of it, `t63c_e2e.py`: HIGH THR 20 -> 70 settles at `0x4600`].

### 3.2 The reader and the values

- **Fetch** (every block, after the magic test): copy rx + `0xa80` of `0x2c29d0` and `0x2c39d0` (15 longs each; the lower
  word in each long's low half) into CmpTail, check each copy (magic, check word), take the newer valid one by the signed
  16-bit difference of the two sequences, accept it when its sequence differs from the held one (equality only), else
  keep the held values. Returns 1 once any tail has been accepted since boot [verified, (r)].
- **Apply**: knob = word / 256 (= 127 x word / 32512, exact: `v << 8` gives v; the stock form `word x (1/32512) x 127`
  truncates to v - 1 for v = 9, 13, 18, 26, 36, 52, 72, 104 [verified, float32]); ATK and REL (stock-table indices)
  take `(word + 0x80) >> 8`, so a settled word one below `v << 8` still gives v; RAT word / 256, which mbcomp rounds to
  the step. Each knob is set only when it differs from the compressor's own word; mbcomp_set clamps (THR, ATK, REL,
  MUP, XOVR 0..127; RAT 0..8) [verified, (r), (n)].
- Words: k 70..75 = LOW THR RAT ATK REL MUP + low/mid XOVR, k 76..81 = MID ... + mid/high XOVR, k 82..86 = HIGH (no
  XOVR). The DSP still sorts the crossovers (mbcomp `mb_xover_coefs`); the laws meet at 1 kHz [verified, CMP1 rows].
- **Skew**: k 60..67 (MIX, SCS) come through the block-old frame image, the tail live: one block apart. Ignored, as
  planned.

### 3.3 The fallback: CMP1's bands, not the stock routine

Until the first valid tail the bands run exactly as on CMP1 (all three from the stock k 60..64, crossovers 196 Hz /
2.61 kHz). Chosen over the plan's "call the stock `0xb8541d`" because:
1. **The tail path on silicon is the one link the emulator cannot show** (the PUSHR data halves on the wire into the
   DSP's receive DMA). If it fails on the unit, CMP2 sounds and meters exactly like CMP1, which the owner knows, and the
   band knobs do nothing: a safe, recognisable symptom. With the stock fallback the 3-band compressor would disappear
   and the band meters go dead.
2. **No new path in the master compressor**: the stock fallback needs a run-time switch between two compressors and a
   hand-over when the first tail arrives (two states, a jump in the sound), in the one place where a fault is audible at
   boot (T6.4 6.1 #1). CMP1's path is the code already on the unit.
3. **It is provable bit for bit**: zero tails -> CMP1's output (verify_cmp (h)); invalid tails -> CMP1's output
   (verify_cmp2 (z)); MIX 0 -> FTD1's output either way ((c), (m)).
What it gives up: a DSP image that is bit-exact stock on a main OS without comp-link. CMP2's section 7 only ships with
CMP2's main OS [inferred: no other container carries it].

On the unit the tail arrives from the first frame the ColdFire sends (the hook is in the image from boot and `.run` is
copied before the OS starts), so the fallback lasts at most the first block or two [inferred].

## 6. Limits, and what to expect

1. **Values are not saved** (CMP3). k 70..100 are neither saved nor reset by a kit or project load (T6.5 5), so the band
   values carry over across kit changes and project loads until power-off [inferred from T6.5; not re-run here].
2. **After power-on every band is off** (all band words 0: RAT 1.00, THR 0, ATK 0, REL 0, MUP 0.0dB, 30 Hz / 1.0 kHz)
   [verified: C2EM warm snapshot; unit inferred], so the compressor does nothing at any MIX until a band's RAT is set (at
   MIX > 0 the output is the band sum, an allpass; at MIX 0 the raw input). A new kit takes the rows' defaults (THR 32,
   RAT 4.00, ATK 24, REL 32, MUP 12.1dB, 196Hz, 2.6k) [inferred, `FUN_400e7140`, as on CMP1]. **A kit set up on
   CMP0/CMP1 does not bring its compression with it**: it plays with whatever the band knobs hold (after power-on, none);
   the hidden k 60..64 drive the sound only in the fallback. They still follow the kit and MIDI CC 111-115.
3. **The tail reaching the DSP on silicon** is not proved: the emulator shows the wire frame the driver sends, sharcvm
   the DSP reading the receive buffer; the step between (the DSPI2 wire and the DSP's SPI DMA) is the unit's [inferred:
   the stock payload takes the same path; dnfw/angellinares found the tail bytes free on 1.11]. Symptom if it fails:
   CMP1's sound, band knobs without effect.
4. **Kit change, paste, clear, undo with the sequencer running** (the lazy recopy path to row 16) is a unit check (the
   emulator never runs that loop) [inferred, T6.4 3.4].
5. **No p-locks, no MIDI CC/NRPN** on the band rows (k 70..86) [verified CMP1 rows].
6. **Louder than stock** at the same knobs is accepted; no makeup trim. Three bands with up to +24 dB makeup each can
   reach the master's 0.693 ceiling (verify2 (n): peak 0.693).
7. **An older tail can be taken** when the newest buffer is torn (equality rule): one frame of older, smoothed values,
   inaudible [inferred].
8. **The check word** is a 16-bit sum: compensating errors in two words pass [inferred]; the values are clamped anyway.
9. **The compressor's code slot** has 174 bytes left in `t38_code3` and 5,022 in `t38_code2`; CMP3 adds no DSP code
   [inferred, plan 5].
